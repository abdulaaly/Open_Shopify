# Security Policy

## Supported Versions
Security updates are applied to the active development release branch.

| Version | Supported |
| :--- | :--- |
| 1.0.x | Yes |

## Reporting a Vulnerability
If you discover a security issue or vulnerability within VENDR, please report it privately:
- Email: security@vendr.local
- Please include reproduction steps, environment details, and affected components.
- We will respond within 48 hours and coordinate a coordinated disclosure timeline.
